# TutorLink Ethiopia

TutorLink Ethiopia is a modern tutoring marketplace for Ethiopian university students and graduates. The platform helps students and recent graduates find flexible home and online tutoring jobs while giving parents a way to discover qualified tutors for their children.

## Overview

This project is built as a React + TypeScript app with TanStack Start and Vite. It includes:

- a landing page for tutoring opportunities
- tutor job listings and subject filtering
- tutor registration/profile flows
- parent and student onboarding sections
- responsive UI with motion-based interactions

## Features

- Home and online tutoring job discovery
- Subject-based browsing for tutoring opportunities
- Tutor profile creation and onboarding flow
- Parent-friendly discovery experience
- Responsive, polished UI built with Tailwind CSS and shadcn-style components
- Animated sections and transitions using Framer Motion

## Tech Stack

- React
- TypeScript
- Vite
- TanStack Start / React Router
- TanStack Query
- Tailwind CSS
- Framer Motion
- shadcn/ui-inspired component structure

## Getting Started

### Prerequisites

- Node.js 18+
- npm or bun

### Install dependencies

```bash
npm install
```

or

```bash
bun install
```

### Run the app locally

```bash
npm run dev
```

The app will start in development mode using Vite/TanStack Start.

## Available Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
npm run test
```

## Production Build

```bash
npm run build
```
